Buatlah fungsi yang menghitung rata-rata dari deret bilangan yang dibentuk oleh selisih kuadrat dua bilangan berurutan, dari 1 hingga n.

CODE TEMPLATE:
def hitung_rata_rata(n):
    # Write your code here
    pass

JAWABAN:
def hitung_rata_rata(n):
    deret = [(i+1)**2 - i**2 for i in range(1, n+1)]
    return sum(deret) / len(deret)

PENJELASAN:
Fungsi ini menggunakan list comprehension untuk menghitung selisih kuadrat dua bilangan berurutan, dari 1 hingga n, kemudian menghitung rata-rata dari deret tersebut.

SOAL:
Apa kelebihan algoritma Binary Search dibandingkan dengan Linear Search?

CODE TEMPLATE:
def binary_search(arr, target): 
  low, high = 0, len(arr) - 1 
  while low <= high: 
    mid = (low + high) // 2 
    if arr[mid] == target: 
      return mid 
    elif arr[mid] < target: 
      low = mid + 1 
    else: 
      high = mid - 1 
  return -1

OPSI:
  Kompleksitas waktu yang lebih tinggi
  Dapat mencari elemen pada array yang tidak terurut
  Lebih cocok untuk array dengan jumlah elemen yang kecil
  Memiliki kompleksitas waktu yang lebih rendah (O(log n))

JAWABAN:
D

PENJELASAN:
Binary Search memiliki kelebihan kompleksitas waktu yang lebih rendah (O(log n)) dibandingkan dengan Linear Search (O(n)) karena Binary Search dapat membagi ruang pencarian menjadi dua bagian pada setiap iterasi.

Buatlah fungsi yang melakukan pencarian nilai maksimum dalam sebuah daftar bilangan bulat dan mengembalikan indeks nilai maksimum tersebut.

    # Write your code here

JAWABAN:
def cari_maksimum(daftar):
    if len(daftar) == 0:
        return None
    maksimum = daftar[0]
    indeks_maksimum = 0
    for i in range(1, len(daftar)):
        if daftar[i] > maksimum:
            maksimum = daftar[i]
            indeks_maksimum = i
    return indeks_maksimum

PENJELASAN:
Fungsi pencarian nilai maksimum bekerja dengan membandingkan setiap elemen dalam daftar dan mengupdate nilai maksimum jika ditemukan nilai yang lebih besar. Proses ini berlanjut hingga semua elemen dalam daftar telah diperiksa, dan kemudian fungsi mengembalikan indeks nilai maksimum.
