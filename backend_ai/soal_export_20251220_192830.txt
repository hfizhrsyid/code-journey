Buatlah fungsi yang melakukan pencarian biner pada sebuah daftar angka yang telah diurutkan untuk menemukan indeks dari sebuah target. Jika target tidak ditemukan, kembalikan nilai -1.

CODE TEMPLATE:
def binary_search(arr, target):
    # Write your code here
    pass

JAWABAN:
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

PENJELASAN:
Pencarian biner bekerja dengan membagi daftar menjadi dua bagian dan memeriksa apakah target berada di bagian kiri atau kanan. Proses ini diulangi sampai target ditemukan atau daftar menjadi kosong.
