Apa perbedaan utama antara tipe data list dan tuple dalam Python?

OPSI:

  Tuple dapat diubah, tetapi list tidak dapat diubah dan lebih lambat

            if 'string' in result:

        elif isinstance(char, int):
            if 'integer' in result:
                result['integer'] += 1
            else:
                result['integer'] = 1
        else:
            if 'other' in result:
                result['other'] += 1
            else:
                result['other'] = 1
    return result

    for char in input_str:
        if char.isdigit():
            result[char] = 'Integer'

            result[char] = 'String'

            result[char] = 'Simbol'
    return result

    if operator == '+':
        return angka1 + angka2
    elif operator == '-':
        return angka1 - angka2

        return angka1 * angka2
    elif operator == '/':
        if angka2 != 0:

            return 'Tidak dapat membagi dengan nol'
    else:
        return 'Operator tidak didukung'

PENJELASAN:

    # Write your code here

def quick_sort(arr, ascending=True):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    if ascending:
        return quick_sort(left, ascending) + middle + quick_sort(right, ascending)
    else:
        return quick_sort(right, ascending) + middle + quick_sort(left, ascending)

PENJELASAN:
Fungsi Quick Sort bekerja dengan memilih suatu elemen dalam daftar yang disebut pivot. Lalu, elemen-elemen lainnya dalam daftar dibagi menjadi dua bagian, yaitu elemen-elemen yang lebih kecil dari pivot dan elemen-elemen yang lebih besar dari pivot. Proses ini dilakukan secara rekursif hingga seluruh daftar terurut.

    # Write your code here
    pass

JAWABAN:
def binary_search(daftar, target):
    low = 0
    high = len(daftar) - 1
    while low <= high:
        mid = (low + high) // 2
        if daftar[mid] == target:
            return mid
        elif daftar[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

PENJELASAN:
Fungsi binary_search ini bekerja dengan membagi daftar menjadi dua bagian dan membandingkan elemen tengah dengan target. Jika elemen tengah lebih besar dari target, maka fungsi memotong setengah kanan daftar dan mengulangi proses. Jika target tidak ditemukan, maka fungsi mengembalikan -1.
