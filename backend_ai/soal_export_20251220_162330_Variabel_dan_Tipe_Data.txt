SOAL:
Apa perbedaan utama antara tipe data list dan tuple dalam Python?

OPSI:
  List dapat diubah, tetapi tuple tidak dapat diubah dan lebih cepat
  Tuple dapat diubah, tetapi list tidak dapat diubah dan lebih lambat
  Keduanya sama, hanya nama berbeda
  List hanya untuk angka, tuple hanya untuk string

JAWABAN:
A

PENJELASAN:
Perbedaan utama antara list dan tuple dalam Python adalah bahwa list dapat diubah (mutable), sedangkan tuple tidak dapat diubah (immutable). Ini berarti Anda bisa menambah, menghapus, atau mengubah elemen dalam list, tetapi tidak bisa melakukannya dalam tuple. Selain itu, tuple umumnya lebih cepat dan lebih efisien dalam hal penggunaan memori dibandingkan dengan list karena sifatnya yang tidak dapat diubah.

Buatlah fungsi yang mengambil sebuah string sebagai input dan mengembalikan sebuah dictionary dengan informasi tentang tipedata dari setiap karakter dalam string tersebut.

CODE TEMPLATE:
def solution(input_str):
    # Write your code here
    pass

JAWABAN:
def solution(input_str):
    result = {}
    for char in input_str:
        if isinstance(char, str):
            if 'string' in result:
                result['string'] += 1
            else:
                result['string'] = 1
        elif isinstance(char, int):
            if 'integer' in result:
                result['integer'] += 1
            else:
                result['integer'] = 1
        else:
            if 'other' in result:
                result['other'] += 1
            else:
                result['other'] = 1
    return result

PENJELASAN:
Penjelasan solusi dan konsep Variabel dan Tipe Data: Fungsi ini menggunakan perulangan untuk memeriksa setiap karakter dalam string input. Kemudian, ia menggunakan metode isinstance() untuk memeriksa tipedata dari setiap karakter dan mengupdate dictionary result berdasarkan tipedata tersebut.

Buatlah fungsi yang mengambil sebuah string sebagai input dan mengembalikan jenis tipe data dari setiap karakter dalam string tersebut.

CODE TEMPLATE:
def tipe_data_karakter(input_str):
    # Write your code here
    pass

JAWABAN:
def tipe_data_karakter(input_str):
    result = {}
    for char in input_str:
        if char.isdigit():
            result[char] = 'Integer'
        elif char.isalpha():
            result[char] = 'String'
        else:
            result[char] = 'Simbol'
    return result

PENJELASAN:
Fungsi ini menggunakan metode isdigit() dan isalpha() untuk menentukan apakah sebuah karakter adalah digit atau huruf. Jika karakter tersebut bukan digit atau huruf, maka dianggap sebagai simbol.
