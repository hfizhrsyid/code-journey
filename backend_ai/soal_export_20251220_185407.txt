SOAL:
Apa yang dimaksud dengan mutable dan immutable dalam konteks variabel dan tipe data di Python?

OPSI:
  A. Mutable merujuk pada variabel yang tidak dapat diubah, sedangkan immutable merujuk pada variabel yang dapat diubah.
  B. Mutable dan immutable keduanya merujuk pada kemampuan variabel untuk diubah, tetapi mutable lebih cepat.
  C. Mutable merujuk pada tipe data yang dapat diubah, seperti list, sedangkan immutable merujuk pada tipe data yang tidak dapat diubah, seperti integer.
  D. Mutable merujuk pada tipe data yang dapat diubah secara internal, seperti list, sedangkan immutable merujuk pada tipe data yang tidak dapat diubah secara internal, seperti string dan integer.

JAWABAN:
D

PENJELASAN:
Jawaban D benar karena mutable dan immutable merujuk pada kemampuan suatu tipe data untuk diubah secara internal. Tipe data mutable seperti list dan dictionary dapat diubah secara internal setelah dibuat, sedangkan tipe data immutable seperti integer, float, dan string tidak dapat diubah secara internal setelah dibuat. Opsi A salah karena mutable sebenarnya merujuk pada kemampuan untuk diubah, bukan tidak dapat diubah. Opsi B salah karena tidak ada perbedaan kecepatan antara mutable dan immutable. Opsi C salah karena, meskipun list adalah contoh tipe data mutable, dan integer adalah contoh tipe data immutable, definisi ini tidak lengkap dan tidak mencakup semua kasus.

SOAL:
Apa perbedaan antara tipe data integer dan float dalam Python?

CODE TEMPLATE:
null

OPSI:
  A. Integer digunakan untuk bilangan bulat, float untuk bilangan kompleks
  B. Integer dan float keduanya digunakan untuk bilangan bulat
  C. Float digunakan untuk bilangan bulat, integer untuk bilangan desimal
  D. Integer digunakan untuk bilangan bulat, float untuk bilangan desimal

JAWABAN:
D

PENJELASAN:
Perbedaan antara tipe data integer dan float dalam Python adalah bahwa integer digunakan untuk menyimpan bilangan bulat, seperti 1, 2, 3, sedangkan float digunakan untuk menyimpan bilangan desimal, seperti 3.14 atau -0.5. Jawaban D benar karena integer memang digunakan untuk bilangan bulat dan float untuk bilangan desimal. Opsi A salah karena float tidak digunakan untuk bilangan kompleks, melainkan untuk bilangan desimal. Opsi B salah karena integer dan float memiliki kegunaan yang berbeda. Opsi C salah karena float digunakan untuk bilangan desimal, bukan bilangan bulat.

SOAL:
Apa perbedaan antara tipe data 'list' dan 'tuple' dalam Python?

CODE TEMPLATE:
null

OPSI:
  A. List dapat diubah, tuple tidak dapat diubah, dan list lebih lambat
  B. Tuple dapat diubah, list tidak dapat diubah, dan tuple lebih cepat
  C. Keduanya dapat diubah, tapi list lebih cepat
  D. List dapat diubah, tuple tidak dapat diubah, dan tuple lebih cepat

JAWABAN:
D

PENJELASAN:
Perbedaan utama antara list dan tuple adalah bahwa list dapat diubah (mutable), sedangkan tuple tidak dapat diubah (immutable). Selain itu, tuple lebih cepat daripada list karena Python dapat melakukan optimasi yang lebih baik pada struktur data yang immutable. Oleh karena itu, opsi D adalah jawaban yang benar.
